# ألبوم صور E.M.C

ده فولدر صور الموقع. كل صورة ليها اسم ثابت، والموقع بيقرأ الصور من هنا مباشرة.

## الصور الموجودة
الفولدر فيه 21 صورة جاهزة بمقاس 800×600، تكفي للرفع على GitHub فوراً.

## تحويلها لجودة HD (اختياري ومُستحسن)
لصور أوضح على شاشات الكمبيوتر الكبيرة، شغّل السكريبت مرة واحدة وهو هيستبدل الصور بنسخ عالية الجودة بنفس الأسماء:
- **ويندوز:** دبل كليك على `download-images.bat`
- **ماك / لينكس:** افتح التيرمينال في الفولدر ده واكتب `sh download-images.sh`
