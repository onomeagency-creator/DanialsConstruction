# E.M.C — For Constructions & Supplies

موقع شركة **E.M.C** للتشطيبات الفاخرة والتصميم الداخلي. الموقع عربي (من اليمين للشمال) وموجّه لعملاء Class A، ومتظبط إنه يشتغل على الكمبيوتر واللاب توب والتابلت والموبايل.

## هيكل الملفات
```
emc-website/
├── index.html          ← الصفحة الرئيسية
├── assets/             ← ملفات الكود
│   ├── css/style.css
│   └── js/main.js
└── images/             ← ألبوم الصور
    ├── hero-1.jpg … work-10-guest-bath.jpg   (21 صورة)
    ├── logo/           (اللوجو + الأيقونة)
    ├── download-images.bat / .sh   (تحويل الصور لجودة HD)
    └── README.md       (دليل الألبوم: كل صورة مكانها فين)
```

## أقسام الموقع
- **شاشة تحميل** باللوجو المتحرك.
- **الرئيسية:** سلايدر صور بحركة بطيئة، وكلمات بتتبدل (بيتك / فيلتك / مساحتك / حلمك).
- **شريط متحرك** فيه الخدمات.
- **من نحن:** تبويبات وصور بتظهر بحركة ستارة.
- **أرقام** بتتعد لوحدها.
- **الخدمات:** 6 خدمات.
- **اكتشف ستايلك:** مودرن دافئ، جابندي، نيو كلاسيك، مع ألوان وخامات كل ستايل.
- **معرض الأعمال:** فيه فلترة، والصورة بتكبر لما تدوس عليها.
- **قبل وبعد:** سلايدر بتسحبه.
- **حاسبة التكلفة الذكية:** بتحسب التكلفة ومدة التنفيذ التقريبية، وبتبعتها على واتساب.
- **رحلة المشروع** في 5 خطوات.
- **آراء العملاء.**
- **فورم حجز معاينة** بيتبعت على واتساب.

**على الموبايل:**
- القائمة بتفتح شاشة كاملة، والروابط فيها كبيرة ومترقّمة.
- فيه شريط تنقّل تحت زي التطبيقات: الرئيسية، أعمالنا، التكلفة، الستايلات، واتساب.

## الرفع على GitHub Pages
1. اعمل Repository جديد على GitHub، مثلاً `emc-website`.
2. **Add file → Upload files**، واسحب **محتويات** فولدر `emc-website` كلها: `index.html` وفولدر `assets` وفولدر `images`.
3. **Commit changes**.
4. من **Settings → Pages** اختار `Branch: main` و `/ (root)` واضغط **Save**.
5. بعد دقيقة أو اتنين هيبقى الموقع شغال على `https://USERNAME.github.io/emc-website/`. الرابط ده بيفتح على الموبايل واللاب توب والكمبيوتر.

## بيانات لازم تتأكد منها
| المكان | التعديل |
|---|---|
| `assets/js/main.js` ← `WHATSAPP_NUMBER` | رقم الواتساب (حالياً 01225799224) |
| `index.html` ← قسم التواصل والفوتر | الإيميل والمواعيد |
| `index.html` ← روابط السوشيال (`href="#"`) | لينكات صفحات الشركة |
| `index.html` ← الأرقام (`data-count`) | أرقام الشركة الحقيقية |
| `index.html` ← آراء العملاء | آراء حقيقية |
| `index.html` ← أزرار الحاسبة (`data-min` / `data-max`) | سعر المتر لكل مستوى تشطيب |

## الصور
الصور الحالية تصورية من Unsplash، كلها تصميمات داخلية من غير أشخاص، ومسموح استخدامها مجاناً. ولتغيير أي صورة: حط صورتك في `images/` **بنفس الاسم**، والموقع هيعرضها على طول.
